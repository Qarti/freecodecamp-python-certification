# Budget App

This project is part of the freeCodeCamp Python Certification.

## 📌 Description

A Python application that allows users to manage budgets across different categories and visualize spending using a text-based chart.

## ⚙️ Features

- Create budget categories
- Deposit and withdraw money
- Transfer funds between categories
- Check balances
- Generate a spending chart by category

## 🧠 Concepts Used

- Classes and objects (OOP)
- Lists and dictionaries
- String formatting
- Loops and conditionals
