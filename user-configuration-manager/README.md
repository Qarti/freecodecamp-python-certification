# User Configuration Manager

This project is part of the freeCodeCamp Python Certification.

## 📌 Description

A simple Python program that allows users to manage configuration settings such as theme, notifications, and volume.

## ⚙️ Features

- Add new settings
- Update existing settings
- Delete settings
- View all current settings

## 🧠 Concepts Used

- Dictionaries
- Functions
- String manipulation
- Conditional logic

## ▶️ Example

Theme: dark
Notifications: enabled
Volume: high
