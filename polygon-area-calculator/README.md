# Polygon Area Calculator

This project is part of the freeCodeCamp Python Certification.

## 📌 Description

A Python program that uses object-oriented programming (OOP) to model rectangles and squares, and perform geometric calculations.

## ⚙️ Features

- Calculate area, perimeter, and diagonal of rectangles
- Generate visual representations using `*`
- Determine how many shapes fit inside another
- Square class inherits from Rectangle (OOP inheritance)

## 🧠 Concepts Used

- Classes and objects
- Inheritance
- Method overriding
- Encapsulation
- Mathematical calculations
